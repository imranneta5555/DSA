# 8 Conclusion and Self-Assessment

This report created a linked list of twelve cells and developed an algorithm that inserts a new cell at its end, by traversing to the last cell and replacing its Λ with the address of New. The algorithm runs in O(n) time and O(1) extra space. It handles the empty list and the other edge cases, and it preserves the integrity of the list by clearing Link(New) before re-linking and by refusing a cell that is already in the list. The flowchart corresponds exactly to the pseudocode and to the C++ implementation, and the behaviour was confirmed by automated tests, memory-checking tools and deliberate fault injection.

The most useful lesson from the work was that an algorithm which is correct for the normal case can still damage a data structure when it receives unusual input. Working out what would happen if New were already in the list showed that the simplest version of the algorithm loses cells or creates a cycle, a fault that a straightforward demonstration would never reveal. Writing the tests before relying on the results, and then checking that the tests could detect deliberate faults, was what made that kind of fault visible. A natural next step would be to measure the traversal against a tail-pointer version on much longer lists, to quantify the practical cost of the O(n) search.
